# タスク
上記の画像リストの中から、このエリア（メインスポット）に最も適した画像を1つ選択してください。

# 選択基準
1. メインスポットの種類（神社、寺、城、自然景観など）と画像の種類・説明が一致すること
2. エリアの雰囲気や特徴を最もよく表現できる画像であること
3. 完全一致する画像がない場合は、最も近い種類の画像を選択すること
4. 画像の説明文やファイル名も参考にして、最適な画像を判断すること

# 優先順位の例
- 神社 → "神社" > "歴史的建造物" > "寺"
- 寺院 → "寺" > "歴史的建造物" > "神社"
- 城 → "城" > "歴史的建造物"
- 自然景観（山、海、川など） → 該当する自然カテゴリ > "自然景観"
- 温泉 → "温泉・スパ施設" > "温泉街"
- 博物館・美術館 → "博物館" > "美術館" > "歴史的建造物"

# 出力形式
JSON形式で以下のように出力してください。説明や補足は不要です。

```json
{
  "selected_image_id": 5
}
```

# 重要な注意事項
- selected_image_id は利用可能な画像リストに存在するIDを出力してください
- JSON形式以外の出力は不要です
- コードブロック（```json）は含めず、JSON本体のみを出力してください
