あなたは日本の観光地に精通したプロフェッショナルです。指定された観光スポットの詳細情報を分析してください。

# 対象スポット
- スポット名: {{spot_name}}
- 所在市区町村: {{municipality}}、{{prefecture}}

# タスク
このスポットに関する以下の情報を調査し、JSON形式で出力してください。

# 出力項目

1. **latitude** (必須): 緯度（小数点形式、例: 35.6812）
2. **longitude** (必須): 経度（小数点形式、例: 139.7671）
3. **address_detail** (任意): 詳細住所（番地まで、例: "〇〇町1-2-3"）
4. **min_duration_minutes** (必須): 最小滞在時間（分単位、例: 30）
5. **max_duration_minutes** (必須): 最大滞在時間（分単位、例: 120）
6. **spot_role** (必須): スポットの役割。以下のいずれか:
   - "main_destination": メインの目的地（観光の中心となる場所）
   - "sub_destination": サブの目的地（補助的な観光地）
   - "connector_spot": 接続スポット（食事、休憩、移動の中継点）

# 判定基準

## spot_role の判定基準
- **main_destination**: 神社、寺院、城、美術館、博物館、自然景観、テーマパークなど、観光の主目的となる施設
- **sub_destination**: 公園、小規模な史跡、展望台、ビーチなど、メインには劣るが立ち寄る価値がある場所
- **connector_spot**: レストラン、カフェ、道の駅、商店街、土産物店など、休憩や食事のための場所

## min_duration_minutes / max_duration_minutes の目安
- 神社・寺院: 30-60分
- 城郭: 60-120分
- 美術館・博物館: 60-180分
- 自然景観（滝、展望台など）: 20-60分
- テーマパーク: 180-360分
- レストラン・カフェ: 45-90分
- 商店街・市場: 30-90分

# 出力形式
JSON形式で以下のように出力してください。説明や補足は不要です。

```json
{
  "latitude": 35.6812,
  "longitude": 139.7671,
  "address_detail": "〇〇町1-2-3",
  "min_duration_minutes": 30,
  "max_duration_minutes": 90,
  "spot_role": "main_destination"
}
```

# 重要な注意事項
- 座標は必ず正確な値を調査してください（推測ではなく、実在する座標）
- 座標は {{prefecture}}{{municipality}} の範囲内にあることを確認してください
- JSON形式以外の出力は不要です
- コードブロック（```json）は含めず、JSON本体のみを出力してください
- address_detail がわからない場合は null を出力してください
