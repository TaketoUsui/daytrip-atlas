# プラン作成の要件

## 基本方針
1. 日帰り旅行として現実的なプラン（朝出発～夕方帰宅を想定）
2. スポット間の移動時間を考慮した無理のないスケジュール
3. 食事の時間を適切に確保（昼食は必須）
4. 観光の目玉となるメインスポットを含める

## スポット選定
- 最小3箇所、最大5箇所のスポットを選択
- main_destination（メイン目的地）を必ず1-2箇所含める
- connector_spot（食事・休憩スポット）を1箇所以上含める
- 移動距離が短く、効率的に回れる順序で配置

## 滞在時間の設定
- 各スポットの min_duration_minutes と max_duration_minutes を参考に、適切な滞在時間を設定
- 全体の観光時間（移動時間除く）が4-7時間程度になるよう調整

# 出力形式
JSON形式で以下のように出力してください。

```json
{
  "description": "プランの簡単な説明文（100文字程度）",
  "plan_items": [
    {
      "spot_id": 1,
      "duration_minutes": 60,
      "travel_time_to_next_minutes": 15,
      "travel_mode": "walk",
      "description": "このスポットでの楽しみ方（50文字程度）"
    },
    {
      "spot_id": 2,
      "duration_minutes": 90,
      "travel_time_to_next_minutes": 0,
      "travel_mode": null,
      "description": "このスポットでの楽しみ方（50文字程度）"
    }
  ]
}
```

# 項目の説明
- **description**: プランの概要説明（どんな旅行体験ができるか）
- **plan_items**: 訪問するスポットのリスト（訪問順に配置）
  - **spot_id**: 利用可能なスポットのid（数値）
  - **duration_minutes**: そのスポットでの滞在時間（分単位）
  - **travel_time_to_next_minutes**: 次のスポットまでの移動時間（分単位、最後のスポットは0）
  - **travel_mode**: 移動手段（"walk", "train", "car", "bus" のいずれか、最後のスポットはnull）
  - **description**: そのスポットでの楽しみ方や見どころ

# 重要な注意事項
- spot_id は、必ず「利用可能なスポット」のid（数値）を正確に使用してください
- plan_items は訪問順に配置してください
- 最後のスポットの travel_time_to_next_minutes は 0、travel_mode は null にしてください
- コードブロック（```json）は含めず、JSON本体のみを出力してください
- 現実的で実行可能なプランを作成してください
- キャッチフレーズのテーマに合ったスポット選定と順序を心がけてください
