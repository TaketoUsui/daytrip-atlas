# プラン作成の要件

## 基本方針
1. 日帰り旅行として現実的なプラン（朝出発～夕方帰宅を想定）
2. スポット間の移動時間を考慮した無理のないスケジュール
3. 食事の時間を適切に確保（昼食は必須）
4. 観光の目玉となるメインスポットを含める

## スポット選定
- 最小3箇所、最大5箇所のスポットを選択
- main_destination（メイン目的地）を必ず1-2箇所含める
- connector_spot（食事・休憩スポット）を1箇所以上含める
- 移動距離が短く、効率的に回れる順序で配置

## 滞在時間の設定
- 各スポットの min_duration_minutes と max_duration_minutes を参考に、適切な滞在時間を設定
- 全体の観光時間（移動時間除く）が4-7時間程度になるよう調整

# 出力形式
JSON形式で以下のように出力してください。

```json
{
  "plan_title": "プランのタイトル（例: 歴史とグルメを楽しむ〇〇散策）",
  "plan_description": "プランの簡単な説明文（100文字程度）",
  "estimated_duration_minutes": 360,
  "items": [
    {
      "spot_name": "スポット名1",
      "order": 1,
      "duration_minutes": 60,
      "visit_notes": "このスポットでの楽しみ方や見どころ（50文字程度）"
    },
    {
      "spot_name": "スポット名2",
      "order": 2,
      "duration_minutes": 90,
      "visit_notes": "このスポットでの楽しみ方や見どころ（50文字程度）"
    }
  ]
}
```

# 項目の説明
- **plan_title**: プラン全体のタイトル（魅力的でわかりやすいもの）
- **plan_description**: プランの概要説明（どんな旅行体験ができるか）
- **estimated_duration_minutes**: プラン全体の所要時間（分単位、スポット間移動時間含む）
- **items**: 訪問するスポットのリスト
  - **spot_name**: 利用可能なスポットリストに記載されている正確なスポット名
  - **order**: 訪問順序（1から始まる連番）
  - **duration_minutes**: そのスポットでの滞在時間（分単位）
  - **visit_notes**: そのスポットでの楽しみ方や見どころ

# 重要な注意事項
- items の spot_name は、必ず「利用可能なスポット」に記載されている名前を正確に使用してください
- JSON形式以外の出力は不要です
- コードブロック（```json）は含めず、JSON本体のみを出力してください
- 現実的で実行可能なプランを作成してください
