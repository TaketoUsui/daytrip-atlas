# 対象エリア
- エリア名: {{cluster_name}}

# 観光スポットリスト
{{spot_names}}

# タスク
各スポットに対して、以下の基準で分析優先度（1-3）を付与してください。

# 優先度の基準

**優先度 3（隠れ観光スポット）- 最優先**
- 超有名ではないが、観光スポットとしての価値がある
- 地元の人や旅行好きに知られている名所
- 「思いがけない出会い」や「発見」を提供できる
- 日帰り旅行に適した規模感

**優先度 2（定番観光スポット）**
- 観光スポットとして有名で、多くの観光客が訪れる
- 海外からの観光客も多い
- ガイドブックに必ず掲載されているレベル
- 誰もが知っている名所

**優先度 1（散歩スポット）**
- 観光のためにわざわざ訪れるほどではない
- 散歩の途中に立ち寄る程度の場所
- 行く価値はあるが、メインの目的地にはならない
- 公園、小さな神社、商店街など

# 重要な方針
「日帰り地図帳」は、「思いがけない出会い」や「気軽な日帰り旅」のコンセプトを大切にしています。そのため、**隠れ観光スポット（優先度3）を最も重視**します。

# 出力形式
JSON形式で以下のように出力してください。

```json
{
  "priorities": [
    {
      "name": "スポット名1",
      "priority": 3,
      "reason": "評価理由（30文字程度）"
    },
    {
      "name": "スポット名2",
      "priority": 2,
      "reason": "評価理由（30文字程度）"
    }
  ]
}
```

# 項目の説明
- **priorities**: スポットごとの優先度評価のリスト
  - **name**: スポット名（リストに記載されている正確な名前）
  - **priority**: 分析優先度（1, 2, または 3）
  - **reason**: その優先度を付けた簡潔な理由

# 重要な注意事項
- コードブロック（```json）は含めず、JSON本体のみを出力してください
- すべてのスポットに優先度を付与してください
- name は、スポットリストに記載されている正確な名前を使用してください
- 隠れ観光スポット（優先度3）を積極的に見つけてください
