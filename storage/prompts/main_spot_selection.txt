# 対象エリア
- エリア名: {{cluster_name}}

# 観光スポット情報（JSON形式）
{{spots_json}}

# タスク
このエリアで日帰り旅行プランを作成する場合、どのスポットを「メインの目的地」とするべきか、1つだけ選定してください。

# メインスポット選定の基準

1. **プランの中心となる価値**:
   - この場所が旅行の主な目的になり得るか
   - 旅行者が「ここに行きたい」と思える魅力があるか

2. **滞在時間の長さ**:
   - 十分な滞在時間を取れるスポットか
   - min_duration_minutes / max_duration_minutes が長めのスポット

3. **分析優先度**:
   - analysis_priority が高いスポット（3が最優先）
   - 隠れ観光スポットや定番観光スポット

4. **スポットの役割**:
   - spot_role が main_attraction のスポットを優先
   - sub_attraction も候補になり得る

# 出力形式
JSON形式で以下のように出力してください。

```json
{
  "main_spot_id": 123,
  "reason": "選定理由（50文字程度）"
}
```

# 項目の説明
- **main_spot_id**: 選定したスポットのid（数値）
- **reason**: そのスポットを選んだ簡潔な理由

# 重要な注意事項
- コードブロック（```json）は含めず、JSON本体のみを出力してください
- main_spot_id は、必ず提供されたスポット情報のid（数値）を正確に使用してください
- 1つのスポットのみを選定してください
- プラン全体の魅力を最大化できるスポットを選んでください
